Page ReferrersWhich page a visitor was reading when it fetched from the API. Same-site referrers show the page path; anything off-site shows only the hostname; a request that carried no referrer (any direct API or MCP-style call) shows (none). MCP requests are not counted here — they have no page.

Tool OutcomesWhat each tool call returned. ok — the tool answered with content. error — the call failed: the tool threw, or the server rejected the arguments before the tool ran (a mistyped or missing parameter name lands here). empty — the call succeeded but matched nothing, which is how a genuine gap in the corpus looks from outside. Only calls made from worker 1.18.9 onward carry an outcome.

Protocol VersionsThe MCP protocol revision each connecting client asks for when it opens a session. Watch it to catch the moment consumers start speaking a newer revision than this server serves.
Protocol by ClientWhich client asked for which MCP protocol revision, read as revision | client. The Protocol Versions panel shows a revision was requested but not by whom — so a handful of calls for an unreleased revision could be either a census probe walking the spec or a real consumer that has moved ahead of this server. This tells them apart, and that distinction is what an upgrade decision turns on.
